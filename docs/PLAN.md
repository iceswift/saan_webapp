# แผนผลิตภัณฑ์: Saan (ศาล) — ตัวกลางงานศาลพระภูมิครบวงจร

> ชื่อ "Saan" เป็นชื่อชั่วคราวตามชื่อโฟลเดอร์ · ฉบับร่างแรก 8 ต.ค. 2569

## 1. แนวคิดในหนึ่งประโยค

เว็บแอปที่ให้เจ้าของบ้านหรือธุรกิจ **จัดการทุกเรื่องของศาลได้ในที่เดียว** — ซื้อ ตั้ง ถอน ย้าย ซ่อม ดูแล และแก้บน — โดยจับคู่กับร้าน โรงงาน พราหมณ์ และผู้ให้บริการที่ผ่านการตรวจสอบ มีราคาชัดเจนและมีหลักฐานการทำงานทุกขั้น

## 2. สิ่งที่พบจากการศึกษา

### 2.1 ตลาด

| ประเด็น | ข้อมูล | ความน่าเชื่อถือ |
|---|---|---|
| ขนาดตลาดสายมูไทย | ราว 1.5 หมื่นล้านบาท | ตัวเลขจากสื่อ ไม่ระบุวิธีคำนวณ |
| ธุรกิจความเชื่อที่จดทะเบียน | 154 ราย รายได้รวม 227.89 ล้านบาทในปี 2566 (+52.92%) | ข้อมูลกรมพัฒนาธุรกิจการค้า ณ ก.ค. 2567 |
| ลักษณะผู้ขาย | เกือบทั้งหมดเป็นรายเล็ก ขายผ่านหน้าร้าน LINE OA และ Yellow Pages | จากการสำรวจหน้าร้านค้า |

ช่องว่างระหว่าง 228 ล้านกับ 1.5 หมื่นล้านบอกว่าผู้ขายส่วนใหญ่ไม่ได้อยู่ในระบบ ซึ่งเป็นทั้งโอกาส (ตลาดกระจัดกระจาย) และความท้าทาย (ผู้ขายไม่คุ้นกับแพลตฟอร์ม)

### 2.2 ราคาอ้างอิง

| รายการ | ช่วงราคา | หมายเหตุ |
|---|---|---|
| ตัวศาล | เริ่ม 2,700 – 9,000 บาท แล้วแต่ร้าน | ชุดพร้อมโต๊ะหน้าศาล 10,900 – 17,900 บาท |
| ค่าพราหมณ์ พิธีเล็กในบ้าน | 2,000 – 5,000 บาท | เฉพาะค่าทำพิธี |
| ค่าพราหมณ์ พิธีขนาดกลาง | 5,000 – 10,000 บาท | |
| พิธีครบวงจร รวมบายศรีและเครื่องบวงสรวง | 8,000 – 15,000 บาท | |
| เครื่องศาลและของถวาย | ราว 7,000 บาท | จากร้านเดียว ไม่ระบุวันที่ |
| นางรำแก้บน ศาลท้าวมหาพรหม | 260 / 360 / 610 / 710 บาท (2 / 4 / 6 / 8 คน) | ข้อมูลเก่าราวปี 2564 |
| ถอนศาล ย้ายศาล ซ่อม รับศาลเก่า | **ไม่พบราคาเปิดเผยเลย** | ต้องโทรถามทุกร้าน |

งานตั้งศาลหนึ่งครั้งจึงมีมูลค่าราว 15,000 – 40,000 บาทขึ้นไป เป็นงานมูลค่าสูงที่สุดในระบบ

### 2.3 คู่แข่งและช่องว่าง

- **ไม่พบ marketplace ไทยที่ทำเรื่องนี้โดยเฉพาะ** ที่มีอยู่คือร้านรายเดียวที่รับงานครบวงจร เช่น ก.วัฒนาพานิช และโชคนำศิลป์ (รับบูรณะศาลเก่าด้วย)
- Shopee และ Lazada ขายตัวศาลได้ แต่ไม่มีพิธี การติดตั้ง หรือบริการหลังการขาย
- ต่างประเทศมีโมเดลใกล้เคียงในอินเดีย เช่น MuhurtMaza, Utsav, BookSeva (จองพราหมณ์และพิธีออนไลน์ บางรายมีถ่ายทอดสดพิธี) บทเรียนที่ได้คือควรเริ่มจากพื้นที่เดียวให้แน่นก่อนขยาย
- บริการแก้บนแทนมีอยู่แล้วแบบรายย่อย เช่น ร้านไข่ต้มที่วัดหลวงพ่อโสธรส่งถึงจุดแก้บน แต่ไม่เปิดราคาและไม่มีระบบยืนยันผล

### 2.4 ปัญหาของลูกค้าที่ยืนยันได้จากการศึกษา

1. **ราคาไม่โปร่งใส** — แทบทุกบริการต้องโทรถาม และราคาที่ได้มักไม่ชัดว่ารวมอะไรบ้าง
2. **ต้องประสานหลายเจ้า** — ร้านศาล พราหมณ์ ช่างทำฐาน ร้านเครื่องสังเวย และการดูฤกษ์
3. **ไม่รู้จะทิ้งศาลเก่าที่ไหน** — ถึงขั้นมีวัดประกาศรับศาลเก่าเป็นจุดขาย
4. **ไม่มีหลักฐานว่างานทำจริง** — โดยเฉพาะการแก้บนแทน

## 3. ผู้ใช้

**ฝั่งลูกค้า**
- เจ้าของบ้านที่เพิ่งสร้างหรือซื้อบ้าน (ตั้งศาลใหม่)
- ผู้ที่รื้อ ต่อเติม หรือขายบ้าน (ถอน ย้าย ทิ้งศาลเก่า)
- ผู้สูงอายุและลูกหลานที่ดูแลแทน (ซ่อม ดูแลประจำ)
- ธุรกิจ: หมู่บ้านจัดสรร คอนโด โรงแรม โรงงาน สำนักงาน (ดูแลรายเดือน ออกใบกำกับภาษีได้)
- ผู้ที่บนไว้แล้วไปแก้บนเองไม่สะดวก

**ฝั่งผู้ให้บริการ**
- ร้านและโรงงานศาล
- พราหมณ์และผู้ประกอบพิธี
- ช่างซ่อม ช่างทำฐาน ทีมขนย้าย
- ผู้ดูแลประจำ (ทำความสะอาด เปลี่ยนพวงมาลัย ของไหว้)
- ร้านของไหว้ คณะละครรำ ผู้รับแก้บนแทน

**ผู้ดูแลระบบ** — ตรวจสอบผู้ให้บริการ จัดการข้อพิพาท ดูแลการจ่ายเงิน

## 4. บริการ

| หมวด | รูปแบบการขาย | ตัวอย่าง |
|---|---|---|
| ซื้อศาล | แค็ตตาล็อกราคาตายตัว + สั่งทำ | ศาลพระภูมิ ศาลตายาย ศาลพระพรหม ตี่จู้เอี๊ยะ ศาลโมเดิร์น |
| ตั้งศาล | แพ็กเกจราคาตายตัว | พราหมณ์ + เครื่องสังเวย + ฐาน + ดูฤกษ์ |
| ถอน ย้าย รับศาลเก่า | แพ็กเกจ หรือขอใบเสนอราคา | พิธีถอน ขนย้าย นำส่งวัดที่รับ |
| ซ่อมและบูรณะ | ขอใบเสนอราคาจากรูปถ่าย | ทาสี ซ่อมหลังคา เปลี่ยนเสา ระบบไฟ |
| ดูแลประจำ | สมาชิกรายเดือน | ทำความสะอาด เปลี่ยนพวงมาลัย ถวายของ พร้อมรูปรายงาน |
| แก้บน | สั่งของส่งถึงที่ หรือจ้างทำแทน | ไข่ต้ม ผลไม้ ละครรำ พร้อมรูปและวิดีโอยืนยัน |

### ระบบแก้บน

แบ่งเป็นสองส่วนที่ทำงานต่อกัน

**สมุดบน (ใช้ฟรี)** — บันทึกว่าบนไว้กับใคร ที่ไหน ขออะไร สัญญาว่าจะถวายอะไร แล้วเตือนเมื่อถึงกำหนด ส่วนนี้ทำให้ผู้ใช้กลับมาเปิดแอปแม้ยังไม่ได้ซื้ออะไร ข้อมูลเป็นส่วนตัว ไม่แชร์โดยค่าเริ่มต้น

**แก้บน (มีค่าบริการ)** — เมื่อสมหวัง กดจากรายการในสมุดบนได้เลย ระบบดึงสถานที่และของที่สัญญาไว้มาให้ แล้วเลือกได้ 3 แบบ

1. สั่งของแก้บนส่งถึงสถานที่ ลูกค้าไปไหว้เอง
2. จ้างผู้แทนไปแก้บน โดยกล่าวชื่อลูกค้า และส่งรูปกับวิดีโอที่มีพิกัดและเวลากำกับ
3. จองคณะละครรำหรือการแสดง

แพลตฟอร์ม **ไม่รับรองผลของการบน** และไม่ใช้ถ้อยคำเชิงรับประกันโชคลาภ รับรองได้เพียงว่างานถูกทำจริงตามที่สั่ง

## 5. UX

### 5.1 หลักการ

1. **เริ่มจากสิ่งที่ลูกค้าอยากทำ ไม่ใช่จากหมวดสินค้า** — หน้าแรกถามว่า "วันนี้อยากทำอะไรกับศาล" แล้วพาไปทีละขั้น
2. **ราคารวมชัดตั้งแต่ต้น** — ทุกแพ็กเกจแจกแจงว่ารวมอะไร ไม่รวมอะไร มีค่าเดินทางหรือไม่ นี่คือจุดต่างหลักจากตลาดปัจจุบัน
3. **มีหลักฐานทุกขั้น** — รูปก่อน ระหว่าง และหลังงาน ผูกกับสถานะคำสั่งซื้อ
4. **ผู้สูงอายุใช้ได้** — ตัวอักษรใหญ่ ปุ่มใหญ่ ขั้นตอนละหนึ่งคำถาม เข้าสู่ระบบด้วย LINE ไม่ต้องจำรหัสผ่าน
5. **ให้ความรู้โดยไม่ชี้นำความเชื่อ** — อธิบายว่าศาลพระภูมิ ศาลตายาย ศาลพระพรหม ต่างกันอย่างไร โดยเคารพว่าธรรมเนียมต่างกันตามท้องถิ่นและสายครู
6. **มือถือก่อน** — ลูกค้าส่วนใหญ่จะเข้าจากลิงก์ใน LINE

### 5.2 แนวคิดหลัก: "ศาลของฉัน"

ลูกค้าลงทะเบียนศาลครั้งเดียว (รูป ประเภท ตำแหน่ง วันที่ตั้ง) จากนั้นทุกบริการผูกกับศาลนั้น ได้ประวัติการดูแลครบ การแจ้งเตือนที่ตรงกับศาลจริง และการสั่งซ้ำในสองแตะ ธุรกิจที่มีหลายศาลจัดการได้จากหน้าเดียว

### 5.3 เส้นทางหลัก

**ตั้งศาลใหม่**
ตอบ 4 คำถาม (ประเภทสถานที่ งบ สไตล์ พื้นที่) → เลือกศาล → เพิ่มพิธี เครื่องสังเวย และฐาน → ผู้ประกอบพิธีเสนอฤกษ์ 2–3 ช่วง → จ่ายมัดจำ → ติดตามสถานะ → ยืนยันงานเสร็จและรีวิว

**ถอน ย้าย หรือซ่อม**
ถ่ายรูปศาล → ปักหมุด → บอกสิ่งที่ต้องการ → ได้ราคาแพ็กเกจทันที หรือได้ใบเสนอราคา 2–3 เจ้าในเวลาที่กำหนด → เลือก → นัดวัน

**ดูแลประจำ**
เลือกศาล → เลือกความถี่และรายการ → ได้ผู้ดูแลประจำ → รับรูปรายงานทุกครั้งทาง LINE

**แก้บน**
เปิดสมุดบน → กดแก้บน → เลือกรูปแบบ → จ่ายเงิน → รับรูปและวิดีโอยืนยัน

### 5.4 ฝั่งผู้ให้บริการ

ผู้ให้บริการจำนวนมากอายุมากและไม่ถนัดเทคโนโลยี จึงออกแบบให้ **รับงานและตอบผ่าน LINE ได้เกือบทั้งหมด** ทีมงานช่วยลงทะเบียนและถ่ายรูปสินค้าให้ในช่วงแรก หน้าจอหลักมีเพียงงานใหม่ ปฏิทิน และรายได้

## 6. ทิศทาง UI

**หลีกเลี่ยงภาพจำสายมูแบบทองแดงวิบวับ** ความน่าเชื่อถือคือสิ่งที่ตลาดนี้ขาด หน้าตาจึงควรสงบ สะอาด และดูเป็นมืออาชีพ

| องค์ประกอบ | ทิศทาง |
|---|---|
| สี | พื้นขาวนวล ตัวอักษรน้ำตาลเข้มแบบไม้สัก สีเน้นทองหม่นใช้น้อย สีเขียวสำหรับสถานะยืนยัน |
| ตัวอักษร | IBM Plex Sans Thai หรือ Noto Sans Thai Looped (แบบมีหัว อ่านง่ายสำหรับผู้สูงอายุ) ขนาดเนื้อความไม่ต่ำกว่า 16px |
| ภาพ | รูปจริงของศาลและงานจริง ไม่ใช้ภาพสต็อก รูปใหญ่เต็มความกว้าง |
| ความน่าเชื่อถือ | ป้าย "ตรวจสอบแล้ว" จำนวนงานที่ทำ รีวิวพร้อมรูปจากลูกค้าจริง |
| ภาษา | สุภาพ เรียบ ไม่โฆษณาเกินจริง ไม่สัญญาผลลัพธ์ทางความเชื่อ |
| การเข้าถึง | คอนทราสต์ผ่าน WCAG AA พื้นที่แตะไม่ต่ำกว่า 44px รองรับการขยายตัวอักษร |

## 7. ขอบเขต MVP

**ทำในรุ่นแรก**
- ตั้งศาลใหม่ครบวงจร (แค็ตตาล็อก + แพ็กเกจพิธี)
- ถอน ย้าย รับศาลเก่า
- ซ่อม แบบขอใบเสนอราคาจากรูป
- "ศาลของฉัน" และสมุดบน (เฉพาะบันทึกและแจ้งเตือน)
- เข้าสู่ระบบด้วย LINE แจ้งเตือนผ่าน LINE OA
- จ่ายมัดจำด้วย PromptPay QR และบัตร
- ลงทะเบียนและตรวจสอบผู้ให้บริการ รีวิวพร้อมรูป
- หลังบ้านสำหรับแอดมิน

**ทำภายหลัง**
- ดูแลประจำแบบสมาชิก
- แก้บนแบบจ้างทำแทนและจองละครรำ
- บัญชีธุรกิจ หลายศาล ใบกำกับภาษี
- แชตในแอป ถ่ายทอดสดพิธี
- ขยายออกนอกกรุงเทพและปริมณฑล

เหตุผลที่เลือกตั้งศาลและถอนศาลก่อน: มูลค่าต่องานสูงสุด ปัญหาการประสานงานชัดที่สุด และตรวจสอบผลงานได้ง่าย ส่วนแก้บนแทนมีความเสี่ยงเรื่องการโกงสูงกว่า จึงควรเปิดเมื่อระบบตรวจสอบผู้ให้บริการพิสูจน์ตัวแล้ว

## 8. ความน่าเชื่อถือและความปลอดภัย

- ตรวจบัตรประชาชน หน้าร้าน และผลงานของผู้ให้บริการก่อนเปิดรับงาน
- เงินมัดจำถูกพักไว้ และปล่อยให้ผู้ให้บริการเมื่อลูกค้ายืนยันงาน หรือครบเวลาที่กำหนด
- รูปและวิดีโอหลักฐานต้องถ่ายผ่านแอป เพื่อบันทึกพิกัดและเวลา
- นโยบายยกเลิกและคืนเงินชัดเจน โดยเฉพาะกรณีเลื่อนฤกษ์
- ขั้นตอนระงับข้อพิพาทโดยแอดมิน
- รีวิวได้เฉพาะผู้ที่มีคำสั่งซื้อจริง

## 9. โมเดลรายได้ (สมมติฐานที่ต้องทดสอบ)

## 12. กฎหมายที่ต้องตรวจสอบกับทนาย

- **การถือเงินลูกค้า** — พ.ร.บ.ระบบการชำระเงิน พ.ศ. 2560 กำกับบริการรับชำระเงินแทนและการโอนเงิน การพักเงินมัดจำไว้เองอาจเข้าข่ายต้องขอใบอนุญาต ทางออกคือให้ผู้ให้บริการชำระเงินที่มีใบอนุญาตเป็นผู้ถือเงินและแบ่งจ่าย และต้องให้เขายืนยันเป็นลายลักษณ์อักษรว่าใบอนุญาตครอบคลุมรูปแบบนี้
- **กฎหมายแพลตฟอร์มดิจิทัล** — บริการตลาดออนไลน์อยู่ในข่ายต้องแจ้ง ETDA ก่อนเริ่มให้บริการ ต้องมีข้อกำหนดการใช้งานและช่องทางรับแจ้งเนื้อหาผิดกฎหมาย เกณฑ์สำหรับรายเล็กต้องตรวจสอบจากประกาศฉบับล่าสุด
- **PDPA** — เก็บที่อยู่ รูปบ้าน วันเกิด (สำหรับดูฤกษ์) และข้อมูลความเชื่อ ซึ่งข้อมูลความเชื่อทางศาสนาเป็นข้อมูลอ่อนไหว ต้องขอความยินยอมโดยชัดแจ้ง
- **การโฆษณา** — ห้ามอ้างผลลัพธ์ที่พิสูจน์ไม่ได้ ทั้งในข้อความของแพลตฟอร์มและของผู้ให้บริการ
- **ภาษี** — หัก ณ ที่จ่ายและใบกำกับภาษีเมื่อมีลูกค้าธุรกิจ
