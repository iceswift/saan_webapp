# ร่างคำถามถึง Omise สำหรับ Saan

สถานะ: เตรียมให้เจ้าของตรวจและส่งเอง ยังไม่ได้ส่งถึง Omise

หัวข้อ: ขอคำยืนยันรูปแบบ marketplace การคืนเงิน PromptPay และการโอนให้ผู้ให้บริการ — Saan

สวัสดีทีม Omise

เรากำลังพัฒนา Saan ซึ่งเป็น marketplace สำหรับซื้อและติดตั้ง ย้าย ถอน ซ่อม และดูแลศาลพระภูมิ โดยมีร้านหรือผู้ให้บริการอิสระรับงาน ลูกค้าชำระมัดจำ 30% และชำระส่วนที่เหลือหลังตรวจรับงาน แพลตฟอร์มต้องการจ่ายให้ร้านหลังตรวจรับและเมื่อยอดพร้อมโอน ปัจจุบันทดสอบเฉพาะ sandbox ยังไม่เปิดรับเงินจริง

ขอคำยืนยันสำหรับรูปแบบบริการดังนี้ครับ

1. รูปแบบรับชำระแทนร้านหลายรายและรอจ่ายหลังตรวจรับนี้ใช้บัญชี merchant พร้อม third-party recipients ได้หรือจำเป็นต้องใช้ PayFac/สัญญาอื่น? ต้องยื่นข้อมูลธุรกิจและร้านค้าอะไรบ้าง และรอยอดก่อนโอนให้ร้านได้นานเท่าใด?
2. PromptPay guide ระบุว่า Refund API ใช้ไม่ได้ แต่เอกสาร payment-channel terms ที่เผยแพร่มีข้อยกเว้นให้ merchant คืนผ่านวิธีอื่นโดยตรง รบกวนยืนยันเงื่อนไขฉบับที่ใช้กับบัญชีเรา วิธีที่อนุญาต และการตรวจสอบเจ้าของบัญชีผู้รับคืนที่ต้องทำ
3. สำหรับการคืน PromptPay สามารถใช้การโอนจากบัญชีธนาคารของ merchant ได้หรือไม่? ต้องมีหลักฐานหรือแจ้ง Omise อย่างไร? หากเสนอใช้ Omise Transfer API คืนลูกค้า ต้องใช้ recipient/KYC ประเภทใด และได้รับอนุญาตสำหรับกรณีนี้หรือไม่?
4. กรณีคืนเต็มหรือบางส่วน มีข้อจำกัด ระยะเวลา ค่าใช้จ่าย และข้อกำหนดเรื่องค่ารับชำระ/VAT ที่ต้องแจ้งลูกค้าอย่างไร?
5. สำหรับโอนให้ร้าน รบกวนยืนยันค่าธรรมเนียมและ VAT ของบัญชีเรา หน้าราคาปัจจุบันแสดง 20 บาทในช่วงไม่เกิน 2 ล้านบาท แต่เอกสาร schedule บางฉบับแสดง 30 บาท รวมถึงการคิด amount / total_fee / net และกรณีต้องการให้ร้านได้รับยอดสุทธิแน่นอน
6. รอบเงินพร้อมโอน การโอนอัตโนมัติไป default recipient การพักยอด และข้อจำกัดยอดคงเหลือเป็นอย่างไร? สามารถตั้งขั้นตอนให้สอดคล้องกับการตรวจรับงานของลูกค้าได้อย่างไร?
7. Transfer API มี idemp_key: ขอระบุ scope อายุการคุ้มครอง การส่ง key เดิมต่างยอด และวิธีค้นหารายการเดิมเมื่อ POST timeout โดยยังไม่มี transfer ID รวมถึงการยืนยัน paid เทียบกับ sent
8. ใน sandbox ควรจำลองการ verify/activate recipient และ paid/failed transfer อย่างไรให้ตรงกับ live? มีขั้นตอนตรวจรับ integration หรือเจ้าหน้าที่เทคนิคช่วยตรวจหรือไม่?

ขอเอกสารอ้างอิงและคำตอบเป็นลายลักษณ์อักษรเพื่อให้เราออกแบบขั้นตอนและข้อความแจ้งลูกค้าได้ถูกต้องครับ

ขอบคุณครับ
ทีม Saan

หมายเหตุสำหรับผู้ส่ง: ไม่แนบ secret key, OTP, รหัสผ่าน ข้อมูลธนาคารลูกค้า หรือ URL staging ส่วนตัว หาก Omise ต้องการรายละเอียดบัญชีเพิ่มเติม ให้ส่งผ่านช่องทางทางการที่ยืนยันแล้วเท่านั้น
